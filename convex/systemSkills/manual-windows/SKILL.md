# Windows

A **window** is the big editor/viewer for one block: read or edit a document, work in a table, read a PDF, see a transcript. Floating windows sit above the canvas; the canvas stays usable behind them.

## Open
- **Double-click** the block, or select it and press **Enter**, or **Open** in its toolbar, or click a mention pill / search result / bookmark that points to it.
- Select **several** blocks and press Enter: their windows open **tiled** (up to four, for example 2 × 2); windows that were already open are minimized.
- Blocks without a window: Title, Value, Frame (edited on the canvas). On a phone a window opens full screen (see `manual-mobile-and-tablet`).

## Header buttons (left to right)
- The block's icon and **title**. Drag the header to move the window; drag its edges to resize; **double-click the header** to go fullscreen. Dragging the header to the left or right screen edge snaps the window to a third of the screen, to the top edge snaps it to full size (a blue preview shows it).
- **Refresh window** (when available): reloads the view.
- **Save** (check mark when up to date, floppy disk with "Ctrl + S" when there are unsaved changes): Documents and Tables are **drafts until saved**. **Ctrl/⌘+S** saves the top window from anywhere.
- **Edit** (pencil, on types that need it: upload, title…).
- **Navigate to node**: centres the canvas on the block.
- **Panel** (toggle the side panel, see below; closed by default in a floating window, open by default in fullscreen for Documents and PDFs).
- **Minimize** (−): the window becomes a pill in the bottom-right dock (up to 10 minimized windows: "Maximum 10 minimized windows reached").
- **Expand to fullscreen / Exit fullscreen**.
- **Close** (✕). With unsaved changes it asks **"Close without saving?"**: **Save and close**, or **Close without saving** (Tip: press Ctrl S to save without closing).

## Unsaved changes and Nolë
While any window has unsaved changes, sending a message to Nolë is blocked: "Please save or close the modified windows before sending your message." (a red badge with the count also shows in the chat). Reason: Nolë reads saved content only. Save (Ctrl/⌘+S) or close, then send.

## Minimized windows (bottom-right, left of the Bookmarks button)
Each window is a pill with its icon and title. **Click** to restore; **middle-click** to close; on hover: **Go to node** and **Close window**. A "+N" menu holds the overflow, with **Close all minimized (n)**.

## Side panel (Panel button) — three tabs
- **Plan**: depends on the block. Document: **Outline** of headings ("Add headings to generate the outline."). PDF: **Outline** ("No outline available." when none). Audio/Video: **Overview** and **Chapters**, and the transcript (see `manual-blocks-media`). Table: size information. Otherwise "Nothing to show for this node type." (The search field in this tab is not active yet.)
- **Links**: **Backlinks** (blocks that mention this one with @), **Connections** (blocks linked to it on the canvas), **Threads** (Nolë conversations that edited this block, each with **Open**: "No Nolë conversation edited this node yet.").
- **Versions**: list of saved versions ("User · Updated", "Agent · Updated", "User · Restored"…, with time). Click one to **preview** it in the window (a banner offers **Cancel** and **Restore this version**). Details in `manual-undo-history-trash`. You must save pending changes before previewing ("Save your changes before previewing a version.").

## Nolë inside a window (fullscreen only)
In **fullscreen**, a Nolë chat is available without leaving the window, same conversation and tools as on the canvas: for Documents and PDFs it docks on the left side by side with the content; for the other types a **Nolë** button (**N**) at the bottom-left opens it as an overlay. In a floating (non-fullscreen) window use the canvas Nolë panel.

## Good to know
- Changes saved by other people (or by Nolë) show up in an open window when you have no unsaved edits of your own.
- Some pages cannot be embedded in a Link window: use **Open in a new tab**.
- If a window fails to open ("This window could not be opened"), **Reload the page**.
