# Shortcuts cheat sheet

**Mod** = **Ctrl** on Windows/Linux, **⌘** on Mac. Canvas shortcuts work on the desktop layout, when the canvas has the focus (not while typing in a field or editor). Creation and editing shortcuts need edit rights (not for Viewers).

## Open panels and tools
| Keys | Action |
| --- | --- |
| **Mod+K** | Search the open canvas |
| **Mod+P** | Command center (go to a canvas or bookmark), also works from Home |
| **N** | Open / close the Nolë panel |
| **B** | Open / close the Bookmarks list |
| **F** | Draw-a-frame tool on / off (**Esc** leaves it) |

## Create a block at the pointer (single key, no modifier)
**T** Title · **D** Document · **I** Image · **A** Table · **L** Link. Press once, alone: typing a sentence does not create blocks. Other types: the **+** menu.

## Edit the canvas
| Keys | Action |
| --- | --- |
| **Mod+Z** | Undo (your own gestures, this tab) |
| **Mod+Shift+Z** or **Mod+Y** | Redo |
| **Mod+C** / **Mod+V** | Copy / paste selected blocks (pasting system-clipboard files, links or text creates blocks from them) |
| **Mod+D** | Duplicate the selection |
| **Delete** or **Backspace** | Delete the selected blocks / connections |
| **Enter** | Open the selected block(s) in a window (several = tiled); on a Title: edit its text |
| **Mod+S** | Save the top open window |

## Mouse and trackpad
| Gesture | Action |
| --- | --- |
| Left-drag on empty canvas | Selection rectangle (lasso) |
| **Mod+click** | Add / remove a block from the selection |
| **Mod** held during a lasso | Select blocks but skip frames |
| **Middle button** drag, or hold **Space** and left-drag | Pan |
| Wheel / two-finger swipe | Pan |
| **Mod+scroll** (or trackpad pinch) | Zoom (10 % to 400 %) |
| **Mod held while dragging a block** | Carries along the blocks it points to |
| **Shift held while dragging a block or selection** | Alignment guides: snap to the edges, centres and spacing of visible blocks |
| Double-click a block | Open its window |
| Double-click a connection | Edit its label |
| Right-click canvas / block / selection / connection | Context menus |
| **Alt+click** a block | Attach / detach it to Nolë |
| **Alt+click** empty canvas | Attach that position for Nolë |
| **Alt+click** a search result | Attach / detach it to Nolë |
| Click a mention pill, a block pill in Nolë's reply or a search result | Go to that block on the canvas |
| **Mod+click** the same | Open that block's window (go to if it has none) |

## Windows
| Gesture | Action |
| --- | --- |
| **Mod+S** | Save |
| Double-click the header | Fullscreen on / off |
| Drag the header to a screen edge | Snap to a third of the screen (top edge = full) |
| **N** (fullscreen window) | Nolë chat inside the window |

## Nolë chat
| Keys | Action |
| --- | --- |
| **Enter** | Send |
| **Shift+Enter** or **Mod+Enter** | New line |
| **@** | Mention a block |
| Hold **Ctrl+Alt** | Dictate (release to stop) |

## Documents (editor)
| Keys | Action |
| --- | --- |
| **/** | Block menu (headings, lists, callout, date…) |
| **@** | Mention another block |
| **Mod+Enter** | New empty line below the current one |
| **Shift+Mod+Enter** | New empty line above |

## Menus and lists
- **Add a node** menu: ↑ ↓ ← → / Tab to move, **Enter** to create, **Esc** to close.
- **Search**: ↑ ↓ to move, **Enter** to go to the block, **Mod+Enter** to open its window, **Esc** to close.
- **Command center**: ↑ ↓ to move, **Enter** to open, **Esc** to close.
- **Tables**: in a text cell **Enter** saves, **Shift+Enter** adds a line. Bookmark and connection-label fields: **Enter** confirms, **Esc** cancels.

## Phone
No keyboard shortcuts: use the bottom toolbar and the gestures in `manual-mobile-and-tablet`.
